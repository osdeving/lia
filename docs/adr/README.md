# ADRs

Architecture Decision Records live here.

- One decision per file.
- Use a numeric prefix: `0001_<SHORT_TITLE>.md` (UPPERCASE, underscore).
- Keep it short: context, decision, consequences.

ADRs:
- `0001_TOOLCHAIN_STACK.md`

See `docs/en/PROCESS.md` and `docs/pt-br/PROCESS.md` for the full change process.
